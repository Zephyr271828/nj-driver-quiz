# 贡献指南 Contributing

谢谢愿意帮忙！最常见的贡献是修正某一道题的解析。

## 修正一道题

1. 在 `data/questions.json` 里搜 `"id": 123,` 找到那一行（一题一行）。
2. 修改需要改的字段，格式见 [DATA.md](DATA.md)。常见情况：
   - **解析写错**：改 `why` 和 `why_en`，两种语言意思要一致。
   - **原题本身有问题**（选项缺失、中英文对不上、答案存疑）：不要直接改 `a`（答案），先在 `flag` / `flag_en` 里说明问题，并在 PR 里附上 [NJ Driver Manual](https://www.nj.gov/mvc/pdf/license/drivermanual.pdf) 的页码。确认无误后再改答案。
   - **知识卡挂错**：把 `ek` 改成对应的 key，没有合适的就改成 `null`。
3. 运行校验：

   ```bash
   python3 scripts/validate.py
   ```

4. 本地打开页面（`python3 -m http.server 8000`），在「进度总览」里搜题号确认显示正常。
5. 提 PR，标题里写上题号，例如 `fix(#123): 解析说反了`。

## 写解析的原则

- 先说结论，再说依据。依据尽量对应 Driver Manual 的规定。
- 解释为什么其他选项不对，尤其是容易选错的那个。
- 中文解析里第一次出现的关键英文术语保留原文，例如「车辆注册 (registration)」，方便对照英文考卷。
- `tip` 是一句能记住的口诀，短一点。

## 改代码

全部逻辑在 `js/app.js`，原生 JS，没有构建步骤，改完刷新页面即可。

- 进度格式如果要改，记得同时兼容旧格式（见 `norm()`），别让别人的进度丢了。
- 不要改已有题目的 `id`，进度是按题号存的。
